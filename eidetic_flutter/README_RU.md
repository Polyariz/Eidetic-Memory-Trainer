# Eidetic Memory Trainer - Flutter версия

## 📱 О приложении

**Eidetic Memory Trainer** - это игра для тренировки рабочей памяти, основанная на знаменитом тесте шимпанзе (тест Аюму). Это полный порт оригинального Android-приложения на Flutter/Dart.

### Что это такое?

Игра проверяет вашу способность запоминать и воспроизводить последовательность чисел. Исследования показывают, что нетренированные люди значительно хуже справляются с этим тестом, чем шимпанзе. Это приложение поможет вам тренироваться и улучшить свою рабочую память!

## 🎮 Как играть

1. На экране появляются числа от **1 до 9** в случайных местах на сетке 6×3
2. Запомните расположение всех чисел
3. Нажмите на кнопку с числом **1**
4. Все кнопки изменятся на знак **?**
5. Используя память, нажимайте кнопки по порядку: **2, 3, 4... 9**
6. Если нажмёте неправильную кнопку - потеряете сердце (в лёгком режиме) или проиграете (в сложном)

## 🎯 Режимы игры

### Лёгкий режим (Easy Mode)
- У вас есть **2 сердца** ❤️❤️
- При ошибке теряете одно сердце
- Когда сердца закончатся, следующая ошибка завершит игру
- Каждые 5 побед подряд - получаете бонусное сердце

### Сложный режим (Hard Mode)
- **Нет сердец** - играете на максимум
- Одна ошибка = конец игры
- Для самых смелых и концентрированных!

## 📊 Функции

### Основные возможности
- ⏱️ **60-секундный таймер** с прогресс-баром
- 📈 **Отслеживание серий побед** (streak)
- 🏆 **Рекорды времени** - сохраняется ваш лучший результат
- 📊 **Статистика** - количество игр, побед, процент побед
- 🔊 **Text-to-Speech** - озвучивание результатов
- 🎵 **Звуковые эффекты** при нажатии кнопок
- 🌍 **7 языковых систем счисления**

### Поддерживаемые языки
1. **English** - латиница (1, 2, 3...)
2. **Hindi** - деванагари (१, २, ३...)
3. **Japanese/Chinese** - иероглифы (一, 二, 三...)
4. **Khmer** - кхмерский (១, ២, ៣...)
5. **Formal Chinese** - формальный китайский (壹, 貳, 參...)
6. **Korean** - корейский (일, 이, 삼...)
7. **Old Church Slavonic** - старославянский (Ⰰ, Ⰱ, Ⰲ...)

## 📱 Использование приложения

### Интерфейс

#### Главный экран
- **Прогресс-бар** вверху - показывает оставшееся время (60 секунд)
- **Сердца** в верхнем правом углу - оставшиеся жизни (только в лёгком режиме)
- **Меню** (три точки) - доступ ко всем настройкам
- **Игровое поле** - сетка 6×3 с кнопками

#### Меню настроек
Нажмите на три точки в правом верхнем углу для доступа к:

1. **Reload** - Перезапустить игру (сбросить серию и жизни)
2. **Change language** - Сменить язык чисел
3. **Stats** - Показать статистику:
   - Всего игр
   - Количество побед
   - Процент побед
4. **Turn sounds off/on** - Включить/выключить звуки и озвучивание
5. **Turn hard mode on/off** - Переключить режим сложности

### Игровой процесс

#### Начало игры
1. Запустите приложение
2. Изучите расположение чисел на экране
3. Запомните все позиции
4. Нажмите на кнопку с числом **1**
5. Все числа скроются под знаками **?**
6. Нажимайте кнопки в порядке возрастания

#### Во время игры
- **Правильное нажатие** - кнопка исчезает с анимацией
- **Неправильное нажатие** - теряете жизнь или проигрываете
- **Таймер** - у вас есть 60 секунд, после чего экран становится серым
- **Звуки** - звуковые эффекты при каждом нажатии

#### Окончание игры

**При победе:**
- Зелёный фон
- Показывается время прохождения
- Сравнение с лучшим результатом
- Информация о серии побед
- Кнопки:
  - **Speak** - озвучить результат
  - **No** - выйти из приложения
  - **Yes** - начать новую игру

**При поражении:**
- Красный фон
- Сообщение о проигрыше
- Серия побед сбрасывается
- Кнопки:
  - **No** - выйти из приложения
  - **Yes** - попробовать снова

### Советы и стратегии

1. **Начинайте с малого** - используйте лёгкий режим для практики
2. **Визуализируйте** - создавайте мысленную картину расположения чисел
3. **Группируйте** - делите сетку на зоны для лучшего запоминания
4. **Практикуйтесь** - регулярные тренировки улучшают результат
5. **Используйте язык** - попробуйте разные языковые системы
6. **Следите за временем** - старайтесь не тратить все 60 секунд на запоминание
7. **Сохраняйте спокойствие** - стресс ухудшает память

```bash

flutter doctor -v

# Установите недостающие компоненты согласно инструкциям
```

### Ошибки при установке зависимостей
```bash
# Очистите кэш
flutter clean

flutter pub get

# Если не помогло, удалите pubspec.lock

```

```bash

flutter devices

```

### Ошибки компиляции Dart
- Проверьте версию Dart/Flutter
- Убедитесь, что все import корректны
- Запустите `flutter analyze` для проверки

### Проблемы с TTS на Android
- Убедитесь, что на устройстве установлен движок TTS
- Проверьте, что выбран английский язык в настройках TTS
- Некоторые эмуляторы могут не поддерживать TTS
